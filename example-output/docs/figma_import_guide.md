# راهنمای Import به Figma

۱) پلاگین رایگان 'Figma Tokens' (Tokens Studio) را در Figma نصب کن.
۲) از داخل پلاگین گزینه Import را بزن و فایل design/figma_tokens.json را انتخاب کن.
۳) با دکمه Apply to document، تمام رنگ‌ها/تایپوگرافی/spacing به صورت Styles و Variables در فایل Figma ساخته می‌شوند.
۴) از design/figma_frames_spec.json برای بازسازی سریع چیدمان صفحات به‌عنوان راهنما استفاده کن.
